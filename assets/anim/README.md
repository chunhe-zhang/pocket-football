Animation clips from the Mixamo "Soccer Game Pack" (Adobe Mixamo, downloaded by the project owner),
converted from FBX to a compact JSON: rest pose of the Mixamo rig (world quaternions) and per-bone
quaternion tracks (fingers dropped), hips height as a ratio of the rest height. Retargeted onto the
VRM skeleton at load time (src/avatar.js). Mixamo content is used under Adobe's Mixamo terms.
