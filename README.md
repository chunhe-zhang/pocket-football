# Pocket Football

足球网页游戏，可以四门混战、2v2 组队，或者在长方形球场上踢 6v6 正式比赛。开赛前选角色，每个角色有自己的必杀射门。经典圆场是 24 × 24 米、四角是大圆弧、接近圆形的球场（没有直角死角），四条边各有一个球门，每人守一个门、可以往另外三个门里踢。每人 2 条命，被进两球就出局，他的球门会升起一块挡板封死，最后留下的人获胜。1–4 人参与，空位由电脑补上，支持本地同屏和联机。

**方块乐园（拼运气地图）**：20 × 20 米的正方形小场地，每个人的球门就是自己那一整条边（20 米宽、2.2 米高），每人 3 条命。场地上平铺着 4 × 4 共 16 块方形机关地砖，全都贴着地面——人可以直接从上面跑过去，只有球会被机关影响。每种四块，按 90° 旋转对称摆放，对每个人都一样公平。玩法就是大脚开出去，球自己在机关之间乱窜，最后进了谁的门全看运气。
- **防御结界**：每次开球时，每个球门前都有一道自己颜色的能量护盾。球第一次撞上去会把护盾打碎并被猛地弹回，第二次碰到这个门才能进球，所以不能靠传送门或一脚远射直接得分。护盾碎了 12 秒内没人打进这个门，它会重新长出来；记分牌上名字后面的 🛡 表示这个门还有护盾。
- **漩涡**（中间四块，蓝色）：把球卷着拐个弯再甩出去。
- **传送门**（四个角，紫色一对、粉色一对）：球进一个，从对角那一个出来，速度和方向不变。
- **弹跳垫**（每个球门前偏左一块）：滚过去的球会弹到空中。
- **加速块**（每个球门前偏右一块，橙色 ×1.7）：球穿过时速度变成 1.7 倍。
- 每种机关都有自己的音效：弹跳垫“嘣”的一声，传送门是一高一低的扭曲音，加速块是“咻”地提速，漩涡是打转的水声，护盾碎掉是玻璃碎裂声。
- 球加了黑色描边，脚下有一圈跳动的金色光环，飞在空中时还有一根细线连到地面，在机关堆里也找得到。

**6v6 比赛**：40 × 25 米的长方形六人制球场（四周是围板，没有出界），两端各一个球门，禁区 6 米深、14 米宽。两队各 6 人：1 名门将、2 名后卫、1 名中场、2 名前锋。中场在两名后卫身前拦截，进攻时插上接应。比赛默认 3 分钟，进球多的一队获胜；时间到了还是平局就进入**金球加时**，下一个进球直接获胜。被进球的一方中圈开球。
- 和其他模式一样，每个真人从头到尾控制同一名球员（一个人玩时是蓝队前锋），其余 11 人都是电脑。门将永远由电脑控制，只有门将能在禁区里扑救，后卫在禁区里按抢断键就是正常抢断。
- 电脑按位置跑位：阵型随球整体移动，最近的人去抢、第二个人站在球和球门之间补位，前锋拿球会找空位的队友传球或传中，射程内就射门；门将守在球和球门中间。
- 镜头固定不动，一屏看到整个球场。1–4 人参与；“真人一队”把真人都放在蓝队，“真人对抗”把真人分到两队。联机同样支持。

**角色与必杀射门**：开赛前选角色（多人时每个玩家各选一个，电脑随机）。每个角色头发颜色不同，名字前有角色图标。**每一脚爆射都是必杀射门**（蓄力超过 30% 就算，轻点的传球除外），瞄准线会变成角色颜色，出脚时有短暂的顿帧和震屏。
| 角色 | 必杀 | 效果 |
| --- | --- | --- |
| ⚡ 雷 | 闪电射门 | 速度 ×1.38，几乎不下坠也不减速，带着电弧穿过人墙，碰到的人被电得一个踉跄（0.6 秒） |
| 🔥 火 | 火焰射门 | 速度 ×1.28，火球穿过人群，碰到的人被掀翻 |
| ❄️ 冰 | 冰冻射门 | 速度 ×1.18，穿人的寒冰球，碰到的人被冻在冰块里 1.8 秒 |
| 🌪️ 风 | 旋风射门 | 速度 ×1.2，走 S 形弯道，很难判断落点 |
| 👻 影 | 幻影射门 | 速度 ×1.24，球忽隐忽现，电脑门将不会扑 |
| 🪨 土 | 重炮射门 | 速度 ×1.5，最快最重，撞到谁谁倒，蓄满（80% 以上）时连门将也挡不住 |

**选角色**：选人界面的每张卡片里都是角色的 3D 模型，穿着本角色颜色的球衣在原地待机，选中的那个会慢慢转身展示，点选时还会做个庆祝动作、露出笑脸。

**角色造型**：同一个模型，每个角色有自己的发色和专属配饰，手腕上都戴着本元素颜色的发光护腕，身边绕着两颗本元素颜色的小光球：
- ⚡ 雷：金色头环、两侧闪电发卡，脚踝上一对发光脚环，外侧各挂一道小闪电。
- 🔥 火：头顶三簇火焰头饰、红色围巾（跑起来围巾尾巴会飘），护腕上窜着小火苗。
- ❄️ 冰：冰王冠、雪花发卡，两肩各一簇冰肩甲。
- 🌪️ 风：两侧羽毛发饰、绿色围巾，脚后跟长着小翅膀。
- 👻 影：歪戴的紫色尖帽（帽檐上一颗星）、带浅紫衬里的夜色小披风，两只小幽灵绕着她飘。
- 🪨 土：大耳机、额头上推着的护目镜，两肩是镶黄边的铁甲护肩。

**元素冲刺**：按冲刺键时每个角色都不一样：
- ⚡ 雷：冲刺速度快 12%，身上冒电弧。
- 🔥 火：脚下留一路火，对手踩上去会被烫得弹开。
- ❄️ 冰：脚下留一路冰面，对手踩上去会打滑、很难转向和刹车。
- 🌪️ 风：背后展开翅膀，冲刺快 8%，体力消耗只有六成。
- 👻 影：身体半透明，可以直接穿过人。
- 🪨 土：迎面撞上的对手会被撞倒，身后带着烟尘和速度线。

**打飞**：土的冲撞过人、土铲球和重炮射门会把人撞上半空（冲撞最高 4 米多），翻着跟头落地；火的怒吼爆炎、火焰铲球和火焰射门会把人炸飞出好几米。

**角色专属过人**：带球时按抢断键放出（每 4 秒一次，冷却中按是普通闪身步），电脑也会用。每种都有自己的特效（火身上火焰旋绕、怒吼时火球一圈炸开；冰周身飘雪、地上冒出一圈冰刺；风背后展开绿色羽翼、脚下卷起龙卷风；雷沿路劈出闪电、落地时天上打下一道雷；影脚下开出紫色传送门和光柱；土脚跟喷火、带着速度线冲过去，撞到人有冲击波）：
- ⚡ 雷：Z 字形闪电冲刺，从防守人身边折到他身后，球粘在脚下。
- 👻 影：原地消失，瞬移到防守人身后。
- 🌪️ 风：旋转着高高跃起（约 2.3 米，比以前高得多，飞行距离不变），带着球从人头上飞过去；在空中按射门键就是凌空抽射，从最高点往下砸向球门。
- 🔥 火：停下怒吼，爆炎把身边 3 米内的对手全部震飞倒地。
- ❄️ 冰：寒气爆发，把身边 3 米内的对手冻成冰雕 2 秒（整个人变成冰蓝色、定住不动）。
- 🪨 土：低头往前猛冲，挡路的人被撞飞。

**控制时间**：冰是唯一的长控制（冻成冰雕约 2 秒）；风、影、雷以突进为主；火和土是击飞、击退——人会飞出去很远，但飞得低、落地快，爬起来也快（滞空不到 1 秒，落地后 0.3 秒就能动）。

**角色专属铲球**：每个角色的滑铲也带着自己的能力和特效：
- ⚡ 雷：铲得更快更远，身后拖着电弧，被铲中的人麻痹。
- 🔥 火：一路烧着火焰滑过去，被铲中的人被火焰掀翻。
- ❄️ 冰：在冰面上滑得更远，地上留下一串冰痕，被铲中的人冻成冰雕。
- 🌪️ 风：脚下卷起旋风，把附近的球吸过来。
- 👻 影：球在 1.6～5 米内时，先开一个传送门瞬移到球旁边再铲。
- 🪨 土：铲的范围更大，被铲中的人被撞飞，还有一圈冲击波。

所有过人都会提前算好距离，不会冲出场地、冲进围板，带着的球也不会出界。

闪电、火焰、冰冻射门会穿过场上球员，但站在自己禁区里的门将能用身体挡住（自己也会被电、被烧、被冻）；蓄满的重炮连门将也能穿过去。必杀射门在飞行中不能被停球，速度掉下来以后变回普通的球。

**2v2 组队**：两人一队，开赛时随机分配球门（队友的球门可能相邻，也可能相对）。每人仍然守自己的门、各有 2 条命；球进了队友的门算乌龙，滑铲不会铲倒队友。传球用平传键（贴地），挑传键可以把球传到队友头上让他顶或凌空。电脑队友会跑位接应、迎着球跑过去接、也会给你传直塞和传中。分组可选“真人一队”（真人对电脑）或“真人对抗”。一队两人都出局就输了。

- **角色**：两位动漫风格的 VRM 球员（VRoid 制作），卡通渲染加描边，球衣按队伍上色并印号码；头发、衣袖有弹簧骨骼物理，会眨眼，进球会笑、失球会难过。
- **动作**：跑步、走路、站立使用 Mixamo 的真人动作捕捉动画，在载入时重定向到 VRM 骨骼，步频按实际移动速度同步，脚不打滑；射门、挑射、带球触球、停球、庆祝是叠加在动捕之上的程序化动画。
- **身体细节**：
  - 胸口一直在呼吸，越累呼吸越快越深，体力见底时会张着嘴喘；累坏了站着不动时会弯腰、双手撑在大腿上、抬头盯着比赛。
  - 眼睛会先看向球，头再慢慢转过去（眼睛转得比头更远）。
  - 手：站着时手指自然微屈，跑快了握成拳，庆祝时攥紧拳头。
  - 脚：下蹲、弯腰时脚不会陷进草里，膝盖会跟着弯。
- **身体碰撞**：球和身体各部位（头、胸、胯、大腿、小腿、脚）都是真实的碰撞体（四肢是胶囊体，并且按一帧内的移动轨迹扫过，摆得再快的腿也不会让球穿过去），各有不同的弹性，撞到哪里就从哪里弹开；高速球打在身上会把人撞得踉跄。
- **接球**：看到来球会提前侧身准备，按来球高度自动选择脚内侧停球、大腿停球、胸部停球或头球；来球时按住方向键，第一下触球就把球带向那边。球从身边 1.2 米以内经过时，真人控制的球员会自动横跨一步迎上去把球停住（电脑是 0.85 米），身后来的球和 24 米/秒以内的大力球也能停。
- **扑救**：在自己的禁区（球门前的彩色区域）里按抢断键会变成扑救，朝方向键一侧飞身贴地扑出，伸开的手和身体都能把球挡出去；电脑守门也会扑。
- **抢断**：离球近时按抢断键是正面抢断：身体压上去、伸脚捅球。够不到球（1.3 米外或球在半空）一定抢不到；球贴在对手脚下时很难抢，对手刚把球趟出去、球离脚远时最好抢。另外看角度：正面最容易；对手用身体挡在你和球之间（护球）时很难；从背后抢也难；对手正在做过人动作时几乎抢不到。抢到了球会被捅到你这一侧，对手踉跄一下；没抢到你会失去平衡半秒。
- **铲球**：离球远或在冲刺时按抢断键是滑铲，脚能把球捅走，铲到人会让对方踉跄；电脑也会抢断和铲球，厉害的电脑看到你护球会绕到球的那一侧再抢。
- **闪身步**：角色过人冷却时，带球按抢断键是闪身步：带着球往旁边一闪（方向键选左右，不按就往远离对手的一边闪）。闪的那一下对手很难抢断，滑铲也可能被晃过；电脑也会用。
- **三种出脚**：
  - **射门**：蓄满是重炮。瞄到球门附近会自动修正进门框（离球门越偏修正越少，故意打偏还是能打偏）；什么方向都不按就直接打向球门。
  - **平传**：贴地传给你大致指着的那个队友（45° 左右的范围都算），会算好提前量传到他跑动的路线上；轻点传脚下，蓄力越多越往前送、打身后。不按方向就传给位置最好的队友。传球刚出脚的一小会儿，紧贴着的防守人碰不到球（除非他正在抢断或铲球），没那么容易被断。
  - **挑传 / 挑射**：朝队友是高空传中，球会落在他的头球高度（在禁区附近）或凌空高度（离门远时）；朝着球门、而且没有更靠近球门的队友，就是挑射吊门。
- **精细瞄准**：蓄力时第一下的方向定大方向，之后按住方向键准星会慢慢转过去（约每秒 110°，点一下转两三度），所以用键盘也能打出任意角度；手柄和手机摇杆直接指哪打哪。地上的小点和门上的圈显示球会飞的路线。蓄力条上的金色框里松手是“完美”出脚，几乎没有偏差；蓄满再松手力量最大但会偏、会往上飘。
- **头球**：球在空中时按爆射键，球员会跑到落点，按球的高度自动选择：齐胸的球鱼跃冲顶（整个人飞出去，最有力），高球起跳头球（跳得更高、往下砸），刚好在头部的球站着顶。头球速度最高 25 米/秒左右，带震屏和火花。高过头顶的球按挑射键是倒钩：背对球门翻身凌空一脚，最高 29 米/秒；够不到倒钩的球按挑射键是轻轻往上顶。电脑也会争顶，传中过来的球队友会迎上去头球攻门。
- **一脚出球（配合奖励）**：队友的球还在路上（甚至队友还在蓄力准备传给你）就按键，球员会自动跑到接球点，不停球直接打：地滚球是一脚射门/一脚传，空中球会等它落到腰部高度来一脚**凌空抽射**，更高的球就自动变成头球。一脚出球的射门更准（误差只剩三成）、更快，触球判定也更宽松；回传给刚传你球的人会显示“撞墙配合”。头顶会飘出“凌空抽射! / 一脚射门! / 撞墙配合! / 鱼跃冲顶!”之类的字。自己带球射门和以前一样，没有这些加成。
- **电脑的配合**：电脑传球都用平传，会算提前量，传之前检查传球路线上有没有人（越远检查得越宽）；对方传球时，只有正好在球路上的电脑才会去断。前锋和中场传出球后会前插要回传（二过一），接到队友的球会更常一脚射门、一脚回传或一脚转移；边路下底时会传中，禁区里的队友会头球或凌空。
- **动作**：蓄力时有引腿、侧身、张开手臂的预备动作；轻踢是脚内侧推传；起跳头球会先下蹲再收腿起跳；大力出脚时有火花；加速时身体前倾，急停时后仰；球员之间碰撞会互相挤开、贴着滑过去，不会穿模抖动。
- **界面**：屏幕中间不弹任何大字提示，进球、比分、出局都看顶部记分牌。
- **倒地和爬起**：被滑铲铲中、被火焰或重炮射门打中、被高速撞到时，球员会摔倒（从背后被撞就往前扑，正面被撞就往后倒），躺一下再撑地爬起来。
- **守门员**（6v6）：球靠近时压低重心、双手放在身前准备；扑救反应更快、扑得更远。接得住的球直接抱在怀里（必杀射门只能扑出去），抱球时面向球场，看一眼后手抛给没人盯的队友，没人接应就大力抛向前场。
- **射门和庆祝**：大力射门出脚后身体顺势前送、小跳一步，触球瞬间低头看球。进球庆祝随机：跳舞挥手、跪地张开双臂、张开双臂当飞机、跳起来挥拳。
- **打击感**：球被踢、撞墙、落地时会被压扁再弹回，大力射门和滑铲会掀起草屑；助跑射门更有力，脚碰到球的位置偏了会踢出侧旋；手柄会震动。
- **带球**：触球跟着跑步的步点走，每只脚在往前摆的时候把球拨出去，鞋真的碰到球的那一刻球才走；球被拨出去后回到脚下，再拨下一次；急转、掉头时会用一脚拨球把球带过来，冲刺时球推得更远。只会因为射门、被铲、被对方的脚或身体碰到、撞到东西而丢球。
- **脚与球**：腿部两骨 IK 让鞋真正伸到球上；射门在脚背碰到球的那一刻才出球，带球每一下都由脚把球拨出去，停球时会用鞋底踩住球。
- **足球物理**：重力、空气阻力、旋转产生的弧线（马格努斯效应）、草地滚动阻力、反弹、门柱/横梁碰撞、球网吸收。
- **手感**：自动近身控球、首次触球停球、大力射门的顿帧和镜头震动、球的拖尾、程序化音效，带一点球场混响：射门有皮球“啪”的一声，大力射门还有低频的轰响和破空声；平传声音更圆更轻；头球、胸部停球、铲球、碰撞、门柱（金属回响）、球网、观众（欢呼里有口哨和掌声）都单独做过。每个元素有自己的一套声音，必杀射门、过人技能、铲球和打中人时都会响：雷是电弧噼啪加雷声，火是呼地烧起来的火焰声，冰是一串清脆的冰晶声和冰裂声，风是呼啸的风声和哨音，影是往下滑的幽灵和声，土是低沉的爆响和碎石声。打出凌空、撞墙配合时还有一小段上扬的提示音。
- **电脑**：难度有简单、普通、困难和女友模式（默认）。前三种正常对抗；女友模式下电脑很菜，拿到球就把球传到真人玩家脚下，不铲真人、不抢真人的球，只守自己的门，专门让真人射门。
- **模式**：本地 1–4 人（键盘最多 2 人，3、4 号玩家用手柄），或联机房间（最多 4 人，房间号加入）；地图分经典圆场 / 方块乐园，模式分四门混战 / 2v2 组队 / 6v6 比赛（固定用六人制球场），电脑分简单 / 普通 / 困难 / 女友模式；支持手机触屏。
- **场外**：三面糖果色看台坐满会跟着蹦的观众（进球时全场跳起来，看台上空放烟花），看台两头系着气球串，场边挂彩旗；远处有热气球、摩天轮、城堡、彩虹和飘着的云。
- **画面**：粉色花海与樱花树环绕的球场，各队球门区按颜色区分，白色中圈、彩虹足球和彩虹拖尾。

## 本地运行

```bash
node server/server.js        # 需要 Node 18 以上，不用安装任何依赖
# 打开 http://localhost:8080
```

这个服务器同时提供网页和联机房间。只玩本地模式的话，任何静态服务器都可以（例如 `python3 -m http.server`），但不能直接双击 `index.html`。

## 联机部署（让国内的家人也能一起玩）

联机时，比赛在**房主的浏览器**里运行，服务器只负责转发消息，所以服务器很省资源。国内直接访问 GitHub Pages 和 claude.ai 都不稳定，最稳妥的办法是租一台**香港**的云服务器：国内访问快，而且香港服务器不需要 ICP 备案。

1. 买一台香港的轻量云服务器，例如腾讯云轻量应用服务器或阿里云的香港地域，最便宜的套餐就够用，系统选 Ubuntu 24.04（自带的 Node.js 版本够用）。
2. 在服务器的防火墙或安全组里放行 TCP 80 端口。
3. 登录服务器，安装 Node.js 并取下代码：
   ```bash
   sudo apt update && sudo apt install -y nodejs git
   node -v                      # 需要 18 以上；版本太旧可以改用 NodeSource 的安装脚本
   git clone https://github.com/<你的用户名>/<仓库名>.git pocket-football
   cd pocket-football
   ```
   如果服务器访问 GitHub 慢，也可以在自己电脑上把整个文件夹压缩后用 `scp` 传上去。
4. 让它在后台常驻（开机自启）：
   ```bash
   sudo tee /etc/systemd/system/pocket-football.service > /dev/null <<UNIT
   [Unit]
   Description=Pocket Football
   After=network.target
   [Service]
   WorkingDirectory=$PWD
   ExecStart=$(which node) server/server.js
   Environment=PORT=80
   Restart=always
   [Install]
   WantedBy=multi-user.target
   UNIT
   sudo systemctl enable --now pocket-football
   ```
5. 所有人用浏览器打开 `http://服务器的公网IP/`，进“联机对战”：一个人创建房间，把 4 位房间号发给其他人加入，房主点开始。人不够 4 个时，剩下的球门由电脑守。

**谁当房主：** 房主的网络延迟最低，其他人的操作要先到服务器再到房主那里。如果三个人在国内、一个人在国外，让国内的人创建房间，整体延迟最小。国外的玩家会有大约 0.2–0.3 秒的操作延迟，打得开心没问题，但抢球时会感觉慢半拍。

**其他说明：** 用手机或电脑上的 Chrome、Edge、Safari 打开效果最好，微信内置浏览器也能用但性能差一些。浏览器只在 HTTPS 页面里允许读取手柄，所以用 IP 访问时手柄不能用（联机本来也是每人一台设备，用键盘或触屏即可）。想要域名和 HTTPS，可以给服务器绑一个域名，用 Caddy 反向代理到 80 端口；在中国大陆以外注册域名、指向香港服务器同样不需要备案。

仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`、目录 `/ (root)`，保存后几分钟即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。

## 换成你自己的角色

把任何 VRM 1.0 模型（例如用 VRoid Studio 捏的原创角色，导出时选 VRM 1.0）放到 `assets/models/player.vrm` 即可，动画会自动重定向，踢球的接触点也会按新模型的腿长自动校准。可以先用 `tools/prepare_vrm.py` 去掉法线贴图和缩略图来减小体积。
