# Pocket Football

足球网页游戏，可以四门混战、2v2 组队，或者在长方形球场上踢 5v5 正式比赛。开赛前选角色，每个角色有自己的必杀射门。经典圆场是 24 × 24 米、四角是大圆弧、接近圆形的球场（没有直角死角），四条边各有一个球门，每人守一个门、可以往另外三个门里踢。每人 2 条命，被进两球就出局，他的球门会升起一块挡板封死，最后留下的人获胜。1–4 人参与，空位由电脑补上，支持本地同屏和联机。

**方块乐园（拼运气地图）**：20 × 20 米的正方形小场地，每个人的球门就是自己那一整条边（20 米宽、2.2 米高），每人 3 条命。场地中间塞满了正方形机关，每种四个，按 90° 旋转对称摆放，对每个人都一样公平。玩法就是大脚开出去，球自己在机关之间乱窜，最后进了谁的门全看运气。
- **防御结界**：每次开球时，每个球门前都有一道自己颜色的能量护盾。球第一次撞上去会把护盾打碎并被猛地弹回，第二次碰到这个门才能进球，所以不能靠传送门或一脚远射直接得分。护盾碎了 12 秒内没人打进这个门，它会重新长出来；记分牌上名字后面的 🛡 表示这个门还有护盾。
- **传送门**（紫色一对、粉色一对）：球进一个，从对角那一个出来，速度和方向不变。
- **加速块**（橙色 ×1.7）：球穿过时速度变成 1.7 倍。
- **漩涡**（蓝色）：把球卷着拐个弯再甩出去。
- **命运转盘**（彩虹色 ?，每个球门前一个）：保持速度，往随机方向飞出去。
- **果冻弹块**（粉色方块，两圈共八个）：球撞上去被加力弹回。
- **弹跳垫**（中圈四周）：滚过去的球会弹到空中。
- 球加了黑色描边，脚下有一圈跳动的金色光环，飞在空中时还有一根细线连到地面，在机关堆里也找得到。

**5v5 比赛**：40 × 25 米的经典长方形五人制球场（四周是围板，没有出界），两端各一个球门。两队各 5 人：1 名门将、2 名后卫、2 名前锋。比赛默认 3 分钟，进球多的一队获胜；时间到了还是平局就进入**金球加时**，下一个进球直接获胜。被进球的一方中圈开球。
- 每个真人控制一名场上球员，会自动切到离球最近的队友，队友接到你的传球时也会自动切过去；按 `Q`（双人时 P1 `R`、P2 `,`，手柄 Y，手机“换人”键）手动换人。门将永远由电脑控制，只有门将能在禁区里扑救，后卫在禁区里按抢断键就是正常抢断。
- 电脑按位置跑位：阵型随球整体移动，最近的人去抢、第二个人站在球和球门之间补位，前锋拿球会找空位的队友传球或传中，射程内就射门；门将守在球和球门中间。
- 镜头跟着自己控制的球员和球移动，左下角有小地图。1–4 人参与；“真人一队”把真人都放在蓝队，“真人对抗”把真人分到两队。联机同样支持。

**角色与必杀射门**：开赛前选角色（多人时每个玩家各选一个，电脑随机）。每个角色头发颜色不同，名字前有角色图标。**每一脚爆射都是必杀射门**（蓄力超过 30% 就算，轻点的传球除外），瞄准线会变成角色颜色，出脚时有短暂的顿帧和震屏。
| 角色 | 必杀 | 效果 |
| --- | --- | --- |
| ⚡ 雷霆 | 闪电射门 | 速度 ×1.38，几乎不下坠也不减速，带着电弧穿过人墙，碰到的人麻痹 1.3 秒 |
| 🔥 焰姬 | 火焰射门 | 速度 ×1.28，火球穿过人群，碰到的人被掀翻 |
| ❄️ 冰晶 | 冰冻射门 | 速度 ×1.18，穿人的寒冰球，碰到的人被冻在冰块里 1.8 秒 |
| 🌪️ 旋风 | 旋风射门 | 速度 ×1.2，走 S 形弯道，很难判断落点 |
| 👻 幻影 | 幻影射门 | 速度 ×1.24，球忽隐忽现，电脑门将不会扑 |
| 💣 巨炮 | 重炮射门 | 速度 ×1.5，最快最重，撞到谁谁倒，蓄满（80% 以上）时连门将也挡不住 |

闪电、火焰、冰冻射门会穿过场上球员，但站在自己禁区里的门将能用身体挡住（自己也会被电、被烧、被冻）；蓄满的重炮连门将也能穿过去。必杀射门在飞行中不能被停球，速度掉下来以后变回普通的球。

**2v2 组队**：两人一队，开赛时随机分配球门（队友的球门可能相邻，也可能相对）。每人仍然守自己的门、各有 2 条命；球进了队友的门算乌龙，滑铲不会铲倒队友。没有单独的传球键：往队友那边轻踢一脚爆射就是传球，挑射可以把球传到队友头上让他顶。电脑队友会跑位接应、迎着球跑过去接、也会给你传直塞和传中。分组可选“真人一队”（真人对电脑）或“真人对抗”。一队两人都出局就输了。

- **角色**：两位动漫风格的 VRM 球员（VRoid 制作），卡通渲染加描边，球衣按队伍上色并印号码；头发、衣袖有弹簧骨骼物理，会眨眼，进球会笑、失球会难过。
- **动作**：跑步、走路、站立使用 Mixamo 的真人动作捕捉动画，在载入时重定向到 VRM 骨骼，步频按实际移动速度同步，脚不打滑；射门、挑射、带球触球、停球、庆祝是叠加在动捕之上的程序化动画。
- **身体碰撞**：球和身体各部位（头、胸、胯、大腿、小腿、脚）都是真实的碰撞体（四肢是胶囊体，并且按一帧内的移动轨迹扫过，摆得再快的腿也不会让球穿过去），各有不同的弹性，撞到哪里就从哪里弹开；高速球打在身上会把人撞得踉跄。
- **接球**：看到来球会提前侧身准备，按来球高度自动选择脚内侧停球、大腿停球、胸部停球或头球；来球时按住方向键，第一下触球就把球带向那边。
- **扑救**：在自己的禁区（球门前的彩色区域）里按抢断键会变成扑救，朝方向键一侧飞身贴地扑出，伸开的手和身体都能把球挡出去；电脑守门也会扑。
- **抢断**：离球近时按抢断键是正面抢断：身体压上去、伸脚捅球。能不能抢到看角度：正面最容易；对手用身体挡在你和球之间（护球）时很难；从背后抢也难；对手正在做过人动作时几乎抢不到。抢到了球会被捅到你这一侧，对手踉跄一下；没抢到你会失去平衡半秒。
- **铲球**：离球远或在冲刺时按抢断键是滑铲，脚能把球捅走，铲到人会让对方踉跄；电脑也会抢断和铲球，厉害的电脑看到你护球会绕到球的那一侧再抢。
- **闪身步**：带球时按抢断键，带着球往旁边一闪（方向键选左右，不按就往远离对手的一边闪）。闪的那一下对手很难抢断，滑铲也可能被晃过；电脑也会用。
- **两种出脚**：只有爆射和挑射。爆射轻点就是贴地传球，蓄满是重炮；挑射是高球，可以吊门，也可以传中。都没有自动瞄准、也不会自动找人：球去哪里完全由你瞄。
- **精细瞄准**：蓄力时第一下的方向定大方向，之后按住方向键准星会慢慢转过去（约每秒 110°，点一下转两三度），所以用键盘也能打出任意角度；手柄和手机摇杆直接指哪打哪。地上的小点和门上的圈显示球会飞的路线。蓄力条上的金色框里松手是“完美”出脚，几乎没有偏差；蓄满再松手力量最大但会偏、会往上飘。
- **头球**：球在空中时按爆射键，球员会跑到落点，按球的高度自动选择：齐胸的球鱼跃冲顶（整个人飞出去，最有力），高球起跳头球（跳得更高、往下砸），刚好在头部的球站着顶。头球速度最高 25 米/秒左右，带震屏和火花。高过头顶的球按挑射键是倒钩：背对球门翻身凌空一脚，最高 29 米/秒；够不到倒钩的球按挑射键是轻轻往上顶。电脑也会争顶，传中过来的球队友会迎上去头球攻门。
- **提前出脚**：球还没到脚下就松开爆射或挑射键，球员会自动迎上去，球一进入脚的范围就打出去，可以打一脚出球。
- **动作**：蓄力时有引腿、侧身、张开手臂的预备动作；轻踢是脚内侧推传；起跳头球会先下蹲再收腿起跳；大力出脚时有火花；加速时身体前倾，急停时后仰；球员之间碰撞会互相挤开、贴着滑过去，不会穿模抖动。
- **界面**：屏幕中间不弹任何大字提示，进球、比分、出局都看顶部记分牌。
- **打击感**：球被踢、撞墙、落地时会被压扁再弹回，大力射门和滑铲会掀起草屑；助跑射门更有力，脚碰到球的位置偏了会踢出侧旋；手柄会震动。
- **带球**：触球跟着跑步的步点走，每只脚在往前摆的时候把球拨出去，鞋真的碰到球的那一刻球才走；球被拨出去后回到脚下，再拨下一次；急转、掉头时会用一脚拨球把球带过来，冲刺时球推得更远。只会因为射门、被铲、被对方的脚或身体碰到、撞到东西而丢球。
- **脚与球**：腿部两骨 IK 让鞋真正伸到球上；射门在脚背碰到球的那一刻才出球，带球每一下都由脚把球拨出去，停球时会用鞋底踩住球。
- **足球物理**：重力、空气阻力、旋转产生的弧线（马格努斯效应）、草地滚动阻力、反弹、门柱/横梁碰撞、球网吸收。
- **手感**：自动近身控球、首次触球停球、大力射门的顿帧和镜头震动、球的拖尾、程序化音效（踢球声、门柱声、球网声、观众欢呼、哨声）。
- **电脑**：难度有简单、普通、困难和女友模式（默认）。前三种正常对抗；女友模式下电脑很菜，拿到球就把球传到真人玩家脚下，不铲真人、不抢真人的球，只守自己的门，专门让真人射门。
- **模式**：本地 1–4 人（键盘最多 2 人，3、4 号玩家用手柄），或联机房间（最多 4 人，房间号加入）；地图分经典圆场 / 方块乐园，模式分四门混战 / 2v2 组队 / 5v5 比赛（固定用五人制球场），电脑分简单 / 普通 / 困难 / 女友模式；支持手机触屏。
- **画面**：粉色花海与樱花树环绕的球场，各队球门区按颜色区分，彩虹中圈、彩虹足球和彩虹拖尾。

## 操作

| | 单人 / 联机 | 本地 P1（蓝） | 本地 P2（橙） | 本地 P3、P4（手柄） |
| --- | --- | --- | --- | --- |
| 移动 | WASD / 方向键 | WASD | 方向键 | 左摇杆 |
| 爆射（按住蓄力；轻点＝传球；球在空中＝头球） | Space / J | F | Enter | A |
| 挑射 / 传中（球在空中＝轻顶） | K | G | / | B |
| 冲刺 | Shift | 左 Shift | 右 Shift | RB |
| 抢断 / 铲球 / 扑救；带球时＝闪身步 | L / E | H | . | X |
| 5v5 换人 | Q / I | R | , | Y |

蓄力时按方向键微调瞄准。`C` 切换视角，`M` 静音，`P` / `Esc` 暂停。

## 本地运行

```bash
node server/server.js        # 需要 Node 18 以上，不用安装任何依赖
# 打开 http://localhost:8080
```

这个服务器同时提供网页和联机房间。只玩本地模式的话，任何静态服务器都可以（例如 `python3 -m http.server`），但不能直接双击 `index.html`。

## 联机部署（让国内的家人也能一起玩）

联机时，比赛在**房主的浏览器**里运行，服务器只负责转发消息，所以服务器很省资源。国内直接访问 GitHub Pages 和 claude.ai 都不稳定，最稳妥的办法是租一台**香港**的云服务器：国内访问快，而且香港服务器不需要 ICP 备案。

1. 买一台香港的轻量云服务器，例如腾讯云轻量应用服务器或阿里云的香港地域，最便宜的套餐就够用，系统选 Ubuntu 24.04（自带的 Node.js 版本够用）。
2. 在服务器的防火墙或安全组里放行 TCP 80 端口。
3. 登录服务器，安装 Node.js 并取下代码：
   ```bash
   sudo apt update && sudo apt install -y nodejs git
   node -v                      # 需要 18 以上；版本太旧可以改用 NodeSource 的安装脚本
   git clone https://github.com/<你的用户名>/<仓库名>.git pocket-football
   cd pocket-football
   ```
   如果服务器访问 GitHub 慢，也可以在自己电脑上把整个文件夹压缩后用 `scp` 传上去。
4. 让它在后台常驻（开机自启）：
   ```bash
   sudo tee /etc/systemd/system/pocket-football.service > /dev/null <<UNIT
   [Unit]
   Description=Pocket Football
   After=network.target
   [Service]
   WorkingDirectory=$PWD
   ExecStart=$(which node) server/server.js
   Environment=PORT=80
   Restart=always
   [Install]
   WantedBy=multi-user.target
   UNIT
   sudo systemctl enable --now pocket-football
   ```
5. 所有人用浏览器打开 `http://服务器的公网IP/`，进“联机对战”：一个人创建房间，把 4 位房间号发给其他人加入，房主点开始。人不够 4 个时，剩下的球门由电脑守。

**谁当房主：** 房主的网络延迟最低，其他人的操作要先到服务器再到房主那里。如果三个人在国内、一个人在国外，让国内的人创建房间，整体延迟最小。国外的玩家会有大约 0.2–0.3 秒的操作延迟，打得开心没问题，但抢球时会感觉慢半拍。

**其他说明：** 用手机或电脑上的 Chrome、Edge、Safari 打开效果最好，微信内置浏览器也能用但性能差一些。浏览器只在 HTTPS 页面里允许读取手柄，所以用 IP 访问时手柄不能用（联机本来也是每人一台设备，用键盘或触屏即可）。想要域名和 HTTPS，可以给服务器绑一个域名，用 Caddy 反向代理到 80 端口；在中国大陆以外注册域名、指向香港服务器同样不需要备案。

## 部署到 GitHub Pages

仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`、目录 `/ (root)`，保存后几分钟即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。

## 换成你自己的角色

把任何 VRM 1.0 模型（例如用 VRoid Studio 捏的原创角色，导出时选 VRM 1.0）放到 `assets/models/player.vrm` 即可，动画会自动重定向，踢球的接触点也会按新模型的腿长自动校准。可以先用 `tools/prepare_vrm.py` 去掉法线贴图和缩略图来减小体积。
