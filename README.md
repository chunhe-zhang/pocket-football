# Pocket Football

足球网页游戏（打开默认就是 6v6 · 困难），可以四门混战、2v2 组队，或者在长方形球场上踢 6v6 正式比赛。开赛前选角色，每个角色有自己的必杀射门。经典圆场是 24 × 24 米、四角是大圆弧、接近圆形的球场（没有直角死角），四条边各有一个球门，每人守一个门、可以往另外三个门里踢。每人 2 条命，被进两球就出局，他的球门会升起一块挡板封死，最后留下的人获胜。1–4 人参与，空位由电脑补上，支持本地同屏和联机。

**方块乐园（拼运气地图）**：20 × 20 米的正方形小场地，每个人的球门就是自己那一整条边（20 米宽、2.2 米高），每人 3 条命。场地上平铺着 4 × 4 共 16 块方形机关地砖，全都贴着地面——人可以直接从上面跑过去，只有球会被机关影响。每种四块，按 90° 旋转对称摆放，对每个人都一样公平。玩法就是大脚开出去，球自己在机关之间乱窜，最后进了谁的门全看运气。
- **防御结界**：每次开球时，每个球门前都有一道自己颜色的能量护盾。球第一次撞上去会把护盾打碎并被猛地弹回，第二次碰到这个门才能进球，所以不能靠传送门或一脚远射直接得分。护盾碎了 12 秒内没人打进这个门，它会重新长出来；记分牌上名字后面的 🛡 表示这个门还有护盾。
- **漩涡**（中间四块，蓝色）：把球卷着拐个弯再甩出去。
- **传送门**（四个角，紫色一对、粉色一对）：球进一个，从对角那一个出来，速度和方向不变。
- **弹跳垫**（每个球门前偏左一块）：滚过去的球会弹到空中。
- **加速块**（每个球门前偏右一块，橙色 ×1.7）：球穿过时速度变成 1.7 倍。
- 每种机关都有自己的音效：弹跳垫“嘣”的一声，传送门是一高一低的扭曲音，加速块是“咻”地提速，漩涡是打转的水声，护盾碎掉是玻璃碎裂声。
- 球加了黑色描边，脚下有一圈跳动的金色光环，飞在空中时还有一根细线连到地面，在机关堆里也找得到。

**6v6 比赛**：50 × 31 米的长方形大球场（四周是围板，没有出界），两端各一个球门（宽 4.7 米），小禁区（门将区）7 米深、17 米宽，大禁区 12.5 米深、约 25 米宽。场边没有观众席，只有花丛和远处的公园。镜头固定不动，会自动选一个角度和距离让整个球场铺满屏幕，球员也比其它模式大一号。四周的围板是**波浪形**的：两种长度的波浪叠在一起，凸出凹进各不相同（球门两侧和四个圆角是平的），球撞上去会按那一点的坡度弹开，几乎猜不到会弹向哪里。两队各 6 人：1 名门将、1 名**后卫**、左中右**三人组**、1 名**前锋**。全队整体移动：拿球时所有人一起压上（后卫跟到球后面几米，三人组在球前面拉开三角形接应，前锋顶到最前），丢球时所有人一起后撤到球的身后（前锋也回到中场附近）。整队进攻欲望很强，向前传球、一脚出球给前面的人都更积极，所以更容易打出多人配合。**每队六个人正好是土冰火风影雷六种元素各一个**（你选的元素给你，其余五个分给队友）。比赛分**上下半场**，中场哨响后两队交换场地（球门和禁区的颜色也跟着换），下半场由另一方开球；比赛默认 3 分钟，进球多的一队获胜；时间到了还是平局就进入**金球加时**，下一个进球直接获胜。被进球的一方中圈开球。**越位**：队友传球（或带球触球）的那一刻，你在对方半场、比球更靠前、又比对方倒数第二个人（通常是最后一名后卫，门将算最后一人）更靠前，就处在越位位置；这时你去碰这个球就判越位（平行不算越位，留了一点宽容），对方在犯规地点罚间接任意球：离球最近的防守队员站到球后面，进攻方的人退到 4 米外，短暂停顿后哨响继续。电脑会注意卡越位线跑位，也不会把球传给越位的队友；你传球时如果两个队友方向差不多，会优先传给不越位的那个。传给某个队友的球，路上别的队友不会去截，会让它跑到接球的人脚下。
- 和其他模式一样，每个真人从头到尾控制同一名球员（一个人玩时是蓝队前锋），其余 11 人都是电脑。门将永远由电脑控制，只有门将能在禁区里扑救，后卫在禁区里按抢断键就是正常抢断。
- **站位和跑位**（6v6）：全队拉开站，不再挤成一团。进攻时两个边锋贴着边线拉宽，前锋顶在最后一名后卫身边（不越位），中场站在球的另一侧给出转移的角度，后卫留在后面保护；防守时整体退到球和球门之间，但彼此仍保持距离。队友之间至少隔 4 米左右，拿球的人身边 6 米内不会有自己人凑过去。前锋和边锋会找机会插到对方防线的空当里（跑在越位线以内），持球人被逼抢时，离他最近的队友会跑到七八米外的空位接应。
- **我的队友会给我补位**：你跑到哪个位置，你就暂时是那个位置（后卫插上就当前锋用），电脑队友把剩下的位置分掉，你空出来的位置有人补上。
- **传球更有目的**：电脑传球要往前推进、传到空位、传给前插的人，或者是被逼抢时解围；身前有空当时更愿意自己带球推进，不会没事横传回传，也不会刚接到某人的球就立刻传回给他。**撞墙配合只为了突破**：持球人面前被人挡住、旁边有空位的队友时才会打，传完立刻从防守人身后插上，回传只在能把他送过防守人时才给。
- **尊重个人球权**：队友拿着球（包括带球时球在两次触球之间滚在前面）时，其他队友不会去抢、不会去追，球碰到队友身上也不会被弹走；你的球只有你传出去或者真的丢了，队友才会去拿。
- 电脑按位置跑位：阵型随球整体移动，最近的人去抢、第二个人站在球和球门之间补位，前锋拿球会找空位的队友传球或传中，射程内就射门；门将守在球和球门中间。
- 镜头固定不动，一屏看到整个球场。1–4 人参与；“真人一队”把真人都放在蓝队，“真人对抗”把真人分到两队。联机同样支持。

**角色与必杀射门**：开赛前选角色（多人时每个玩家各选一个；6v6 里每队六种元素各一个）。每个角色头发颜色不同，名字前有角色图标。**每一脚射门都是必杀射门，连轻轻一碰也带着元素**（轻射只是不会更快），每一脚传球也带着元素，瞄准线会变成角色颜色，出脚时有短暂的顿帧和震屏。
| 角色 | 必杀 | 效果 |
| --- | --- | --- |
| ⚡ 雷 | 闪电射门 | 速度 ×1.26，几乎不下坠也不减速，带着电弧穿过人墙，碰到的人被电得一个踉跄（0.6 秒） |
| 🔥 火 | 火焰射门 | 速度 ×1.18，火球穿过人群，碰到的人被掀翻 |
| ❄️ 冰 | 冰冻射门 | 速度 ×1.12，穿人的寒冰球，碰到的人被冻在冰块里 1.8 秒 |
| 🌪️ 风 | 旋风射门 | 速度 ×1.14，走 S 形弯道，很难判断落点 |
| 👻 影 | 幻影射门 | 速度 ×1.16，球忽隐忽现，电脑门将更难判断 |
| 🪨 土 | 重炮射门 | 速度 ×1.3，最快最重，撞到谁谁倒（门将站得住） |

**选角色**：选人界面的每张卡片里都是角色的 3D 模型，穿着本角色颜色的球衣在原地待机，选中的那个会慢慢转身展示，点选时还会做个庆祝动作、露出笑脸。

**渲染风格**：角色用二次元赛璐璐着色——主光只有一道清晰的明暗分界，阴影是带颜色的（皮肤偏暖粉、衣服偏冷蓝、头发是更深更饱和的同色），分界线旁有一道暖色过渡带，边缘有菲涅尔轮廓光把人物从草地上“抠”出来，头发上有一圈高光（天使环）；脸部几乎不打阴影保持干净。描边按部位上色：皮肤是暖棕色线，衣服是队服颜色加深的线。颜色不经过色调映射，保持干净饱和。

**角色造型**：同一个模型，每个角色有自己的发色和专属配饰，手腕上都戴着本元素颜色的发光护腕，身边绕着两颗本元素颜色的小光球：
- ⚡ 雷：金色头环、两侧闪电发卡，脚踝上一对发光脚环，外侧各挂一道小闪电。
- 🔥 火：头顶三簇火焰头饰、红色围巾（跑起来围巾尾巴会飘），护腕上窜着小火苗。
- ❄️ 冰：冰王冠、雪花发卡，两肩各一簇冰肩甲。
- 🌪️ 风：两侧羽毛发饰、绿色围巾，脚后跟长着小翅膀。
- 👻 影：歪戴的紫色尖帽（帽檐上一颗星）、带浅紫衬里的夜色小披风，两只小幽灵绕着她飘。
- 🪨 土：大耳机、额头上推着的护目镜，两肩是镶黄边的铁甲护肩。

**元素冲刺**：按冲刺键时每个角色都不一样：
- ⚡ 雷：冲刺速度快 8%，身上冒电弧；冲刺时抓地更好，转向、急停都更灵，好控制。
- 🔥 火：脚下留一路火，对手踩上去会被烫得弹开。
- ❄️ 冰：脚下留一路冰面，对手踩上去会打滑、很难转向和刹车。
- 🌪️ 风：背后展开翅膀，冲刺快 8%，体力消耗只有六成。
- 👻 影：身体半透明，可以直接穿过人。
- 🪨 土：迎面撞上的对手会被撞倒，身后带着烟尘和速度线。

**打飞**：土的冲撞过人、土铲球和重炮射门会把人撞上半空（冲撞最高 4 米多），翻着跟头落地；火的怒吼爆炎、火焰铲球和火焰射门会把人炸飞出好几米。

**角色专属过人**：带球时按抢断键放出（每 4 秒一次，冷却中按是普通闪身步），电脑也会用。每种都有自己的特效（火身上火焰旋绕、怒吼时火球一圈炸开；冰周身飘雪、地上冒出一圈冰刺；风背后展开绿色羽翼、脚下卷起龙卷风；雷沿路劈出闪电、落地时天上打下一道雷；影脚下开出紫色传送门和光柱；土脚跟喷火、带着速度线冲过去，撞到人有冲击波）：
- ⚡ 雷：Z 字形闪电冲刺（约 3.6 米，折得更小更快），从防守人身边折到他身后，球粘在脚下；冲刺途中推方向键可以拐弯，出来后不会再猛地加速，方便马上接着控球。
- 👻 影：原地消失，瞬移到防守人身后。
- 🌪️ 风：旋转着高高跃起（约 2.3 米，比以前高得多，飞行距离不变），带着球从人头上飞过去；在空中按射门键就是凌空抽射，从最高点往下砸向球门。
- 🔥 火：停下怒吼，爆炎把身边 3 米内的对手全部震飞倒地。
- ❄️ 冰：寒气爆发，把身边 3 米内的对手冻成冰雕 2 秒（整个人变成冰蓝色、定住不动）。
- 🪨 土：低头往前猛冲，挡路的人被撞飞。

**控制时间**：冰是唯一的长控制（冻成冰雕约 2 秒）；风、影、雷以突进为主；火和土是击飞、击退——人会飞出去很远，但飞得低、落地快，爬起来也快（滞空不到 1 秒，落地后 0.3 秒就能动）。

**角色专属铲球**：每个角色的滑铲也带着自己的能力和特效：
- ⚡ 雷：铲得更快更远，身后拖着电弧，被铲中的人麻痹。
- 🔥 火：一路烧着火焰滑过去，被铲中的人被火焰掀翻。
- ❄️ 冰：在冰面上滑得更远，地上留下一串冰痕，被铲中的人冻成冰雕。
- 🌪️ 风：脚下卷起旋风，把附近的球吸过来。
- 👻 影：球在 1.6～5 米内时，先开一个传送门瞬移到球旁边再铲。
- 🪨 土：铲的范围更大，被铲中的人被撞飞，还有一圈冲击波。

所有过人都会提前算好距离，不会冲出场地、冲进围板，带着的球也不会出界。

**三阵营克制**（6v6）：六种元素分成三个阵营——💪 **力量**（火、土：震飞、撞飞）、🌀 **控制**（冰、风：冻住、卷住）、⚡ **灵巧**（雷、影：闪电冲刺、瞬移，快）——**力量 > 控制 > 灵巧 > 力量**。克制是机制，而且只是削弱、不是克死：
- 💪 力量克 🌀 控制：火、土被冻住会很快“挣脱”（冰雕只维持半秒左右，冒一团蒸汽）；被风卷的时候身体沉，只被拉动一点点，脚下的球也吸不走。火的怒吼还会给身边被冻住的队友解冻。
- 🌀 控制克 ⚡ 灵巧：雷的 Z 字冲刺、影的瞬移，带球从冰、风身边经过不会被自动拦下；但控制方可以**主动出手**截住正在放技能的雷和影——冰的寒气爆发把他冻住、风的旋风把他卷出技能、冰铲风铲也能铲到放技能中的雷和影（这不算犯规）。
- ⚡ 灵巧克 💪 力量：火的怒吼爆炎、火铲、土的猛冲、冲撞、土铲、火焰和重炮射门都打不倒雷和影：他们只是被推开一步，还站着，马上就能接着跑。
- 同阵营之间（火对土、冰对风、雷对影）是平手。
- **风现在是控制型**：过人技能起跳前，脚下卷起的旋风会把周围 3.8 米内的对手吸到一起，然后自己从他们头顶飞过去；旋风铲一路把周围的人往铲的方向吸，还能把带球人脚下的球吸走。风的铲球也铲得更远。
- **雷是灵巧型**：雷的麻痹还在，但很短（只是电一下），主要靠速度。
- **无球时也能放技能**（6v6）：没拿球时按抢断键，如果技能冷却好了、身边有能用的目标，就放自己的元素技能去抢球：🔥 火怒吼把身边的人震飞、❄️ 冰寒气把身边的人冻住、🪨 土朝持球人猛冲撞过去、⚡ 雷用一个短促的 Z 字冲刺扑向球把球捅走、👻 影瞬移到球前面、🌀 风原地卷起旋风把周围的人和球都吸过来。无球放的技能冷却更长（约 6 秒）；冷却期间按抢断键还是普通的捅球 / 滑铲。电脑防守也会这样用。
- 电脑防守会优先派克制对方持球人阵营的队友去抢；**按换人键时**，如果对方拿着球，会优先换到能克制他的队友身上。传球也会避开被克制者盯住的队友。克制生效时头顶会冒出“挣脱! / 站稳! / 截住! / 被冻住! / 被卷住! / 闪开! / 穿影!”之类的小字。

**犯规**（6v6，只判滑铲）：先铲到人没碰到球、从背后铲、铲不带球的人都算犯规。从背后铲和铲无球的人给**黄牌**，最后一名防守人放倒 15 米内单刀的人给**红牌**，两黄变一红。**红牌罚下 60 秒**（这期间少一个人踢，60 秒比赛时间后从中线边回场；门将被罚下时离他最近的队友临时去守门）。犯规后有 1 秒左右的**有利**判断：被犯规的一方还在控球就继续比赛（牌照给）；否则在犯规点罚**任意球**（对方退到 4 米外，可以直接射门），犯规发生在防守方小禁区里就罚**点球**：距门 6 米，其他人退到大禁区外，门将在射门前不能动；电脑门将在射门瞬间猜左、中、右，猜错就扑反；你当门将时自动换到门将身上，球踢出后用方向键＋扑救键去扑。计分板队名旁用小方块显示黄牌和红牌数。电脑不会从背后铲、在自己禁区里不铲、已经有黄牌就很少再铲。

**单人元素射门**：雷、火、冰、土的射门会穿过场上球员并把他们电倒、掀翻、冻住、撞飞，但对站在自己禁区里的门将效果不大：他能挡住、扑出，速度不太快的还能直接抱住；**只有冰还会把门将冻住**（球还是被挡出来）。所以一个人带球打进的元素球不再“必进”，个人能力还有发挥的空间，但不多。必杀射门在飞行中不能被停球，速度掉下来以后变回普通的球。

**元素连携（Combo）**：一次配合里每个**一脚出球**的人都把自己的元素加到球上——A 传给 B，B 一脚传给 C，C 一脚射门，这脚射门就带着 A、B、C 三个人的元素。传球本身也带着元素的光和粒子；元素传球对队友没有任何影响，对方去断就会被这些元素轻轻电一下 / 冻一下 / 掀一下，球从他身上弹开。头球攻门也是元素射门，头球摆渡也会把元素传下去。
- 两个人的连携射门更快、穿过所有场上球员、门将抱不住（只能扑出去），并且按元素组合触发特殊效果，射门时头顶会喊出组合名：

- **连携射门自带强力校准**：只要大致朝着球门（比普通射门宽得多的角度），出脚就会被拉进门框以内、离门柱留出余量；飞行中风的 S 弯、雷的折线晃得再厉害，最后也会被拉回门框里、压在横梁以下。
- **大禁区 / 小禁区**：6v6 每个半场有两个区域。**小禁区**就是门将的禁区（7 米深、17 米宽，门将只在这里扑救）；**大禁区**非常大，占半个半场（12.5 米深、约 25 米宽）。射门力度和门将的扑救难度按出脚位置分三档：小禁区里射门最狠、门将最难扑；大禁区里适中；大禁区外的远射明显变慢、门将最好扑——能进，但很少。连携射门同样分档：小禁区里组合特效几乎必定发动，大禁区里有一部分失效，大禁区外大多失效。
- **门将出击**：对方带球冲进禁区直面门将时，门将会出来封角度，扑到脚下把球抱住。
- **连携射门也看距离**：两人连携在禁区附近最厉害，组合特效（瞬移、炸飞、穿门将、冰冻光环……）大多能发动；离得越远越容易“失效”，变成一脚又快又带元素、但门将扑得到的球（20 米外基本都是这样），沿途的光环和对人的效果也会减弱，球速也会随距离下降。所以两人配合也要往前推进，想要远距离也能破门就打出三人合击。
- **三个人以上**的连携射门是“三人合击 / 四人合击”：所有元素一起生效，穿过所有人，门将也挡不住（只有 15 米外才会偶尔失效）。**真正扑不住的球只能来自多人连携**，一个人能完成的无解射门不存在。

**2v2 组队**：两人一队，开赛时随机分配球门（队友的球门可能相邻，也可能相对）。每人仍然守自己的门、各有 2 条命；球进了队友的门算乌龙，滑铲不会铲倒队友。传球用平传键（贴地），挑传键可以把球传到队友头上让他顶或凌空。电脑队友会跑位接应、迎着球跑过去接、也会给你传直塞和传中。分组可选“真人一队”（真人对电脑）或“真人对抗”。一队两人都出局就输了。

- **角色**：两位动漫风格的 VRM 球员（VRoid 制作），卡通渲染加描边，球衣按队伍上色并印号码；头发、衣袖有弹簧骨骼物理，会眨眼，进球会笑、失球会难过。
- **动作**：跑步、走路、站立使用 Mixamo 的真人动作捕捉动画，在载入时重定向到 VRM 骨骼，步频按实际移动速度同步，脚不打滑；跑起来还会叠加肩膀和胯反向扭转、上下起伏、头部稳定、转弯时身体向内侧倾，动作更放松自然；射门、挑射、带球触球、停球、庆祝是叠加在动捕之上的程序化动画。
- **身体细节**：
  - 胸口一直在呼吸，越累呼吸越快越深，体力见底时会张着嘴喘；累坏了站着不动时会弯腰、双手撑在大腿上、抬头盯着比赛。
  - 眼睛会先看向球，头再慢慢转过去（眼睛转得比头更远）。
  - 手：站着时手指自然微屈，跑快了握成拳，庆祝时攥紧拳头。
  - 脚：下蹲、弯腰时脚不会陷进草里，膝盖会跟着弯。
- **身体碰撞**：球和身体各部位（头、胸、胯、大腿、小腿、脚）都是真实的碰撞体（四肢是胶囊体，并且按一帧内的移动轨迹扫过，摆得再快的腿也不会让球穿过去），各有不同的弹性，撞到哪里就从哪里弹开；高速球打在身上会把人撞得踉跄。
- **接球**：看到来球会提前侧身准备，按来球高度自动选择脚内侧停球、大腿停球、胸部停球或头球；来球时按住方向键，第一下触球就把球带向那边。球从身边 1.2 米以内经过时，真人控制的球员会自动横跨一步迎上去把球停住（电脑是 0.85 米），身后来的球和 24 米/秒以内的大力球也能停。
- **扑救**：在自己的禁区（球门前的彩色区域）里按抢断键会变成扑救，朝方向键一侧飞身贴地扑出，伸开的手和身体都能把球挡出去；电脑守门也会扑。
- **抢断**：离球近时按抢断键是正面抢断：身体压上去、伸脚捅球。够不到球（1.3 米外或球在半空）一定抢不到；球贴在对手脚下时很难抢，对手刚把球趟出去、球离脚远时最好抢。另外看角度：正面最容易；对手用身体挡在你和球之间（护球）时很难；从背后抢也难；对手正在做过人动作时几乎抢不到。抢到了球会被捅到你这一侧，对手踉跄一下；没抢到你会失去平衡半秒。
- **铲球**：离球远或在冲刺时按抢断键是滑铲。滑铲威力很大：范围比以前大得多（土更大），地上会亮出一块本元素颜色的判定区，铲的范围一眼就能看清，铲中人或球时会有冲击闪光。但它有代价：一次滑铲要花体力，**铲空了**（既没碰到球也没碰到人）会在地上躺一会儿才爬起来、再扣一大截体力，而且很久不能再铲。电脑也会抢断和铲球，厉害的电脑看到你护球会绕到球的那一侧再抢。
- **带球**：球的运动和脚的动作一致：变向是那一下转向触球（脚碰到球的那一刻）把球拨向新方向，不再是看不见的力把球拉过去；掉头拉球时脚底真的踩在球上；射门/传球时如果脚差一点没碰到，球会先到脚背的位置再被踢出去，不会从空中凭空飞走。球不再像吸在脚上：每一步是用脚把球推出去（冲刺时推得更远，大约领先 0.4–1.3 米），两次触球之间球自己往前滚，人要追上去再碰下一脚。**队友不会抢你的球**：你带着球、或者刚刚碰过球时，队友从旁边跑过、贴着你也碰不走，只有你传给他的球他才会接。自己带着球时，对手光靠贴身挤、伸腿挡是抢不走的，必须按抢断（捅球）或滑铲；捅球想抢走正在带的球也更难了。 带球细节：松开方向键时用脚底把球停在脚下；要掉头（转身超过约 120°）时用脚底把球拉回来再带走，而不是绕一大圈；对手贴近、自己没在冲刺时会自动护球——球换到离对手远的那只脚，步子变小、身体压低，肩膀和手臂顶向防守人。
- **技能射门 / 技能传球**：过人技能（角色技能或冷却时的闪身步）放到一半（雷的折线冲刺途中、影瞬移出来之后、火和冰爆开之后、土冲撞途中），或者刚放完的 0.9 秒内（按早了也会记住，能出脚的那一刻自动出），按射门 / 平传 / 挑传键会**立刻**出脚，力度直接是最舒服的那一档、出脚很准，头顶显示“技能射门! / 技能传球!”——就像风在空中凌空抽射一样，每个角色都鼓励这么打。
- **闪身步**：角色过人冷却时，带球按抢断键是闪身步：带着球往旁边一闪（方向键选左右，不按就往远离对手的一边闪）。闪的那一下对手很难抢断，滑铲也可能被晃过；电脑也会用。
- **三种出脚**：
  - **射门**：蓄满是重炮。瞄到球门附近会自动修正进门框（离球门越偏修正越少，故意打偏还是能打偏）；什么方向都不按就直接打向球门。
  - **平传**：贴地传给你大致指着的那个队友（真人传球 60° 左右的范围都算，按队友正在跑去的位置判断，同方向有几个人时优先没人盯的那个），传给队友的球几乎没有偏差，路上还会轻轻追着他拐过去，会算好提前量传到他跑动的路线上；轻点传脚下，蓄力越多越往前送、打身后。不按方向就传给位置最好的队友。队友传给你的球更准：给真人的提前量更小（更多传到脚下），球在路上还会轻轻追着你现在的位置拐过去，你中途改了跑动方向也接得到。传球刚出脚的一小会儿，紧贴着的防守人碰不到球（除非他正在抢断或铲球），没那么容易被断。
  - **按力度选人**（平传 I、挑传 K 都是）：蓄力多少决定传给多远的队友——轻点传给身边的人（平传约 5 米、挑传约 9 米），蓄满传给最远的那个（平传约 25 米、挑传约 29 米），中间按比例。在按住的方向（大致 70° 以内）上，离这个距离最近、身边空、传球路线上没人、不越位、更靠近球门的队友优先；不按方向就从全场挑。挑传朝着球门、又没有更靠近球门的队友时，还是挑射。
  - **挑传 / 挑射**：朝队友是高空传中，球会落在他的头球高度（在禁区附近）或凌空高度（离门远时）；朝着球门、而且没有更靠近球门的队友，就是挑射吊门。
- **精细瞄准**：蓄力时第一下的方向定大方向，之后按住方向键准星会慢慢转过去（约每秒 110°，点一下转两三度），所以用键盘也能打出任意角度；手柄和手机摇杆直接指哪打哪。地上的小点和门上的圈显示球会飞的路线。蓄力条上的金色框里松手是“完美”出脚，几乎没有偏差；蓄满再松手力量最大但会偏、会往上飘。
- **头球**：球在空中时按爆射键，球员会跑到落点，按球的高度自动选择：齐胸的球鱼跃冲顶（整个人飞出去，最有力），高球起跳头球（跳得更高、往下砸），刚好在头部的球站着顶。头球速度最高 25 米/秒左右，带震屏和火花。高过头顶的球按挑射键是倒钩：背对球门翻身凌空一脚，最高 29 米/秒；够不到倒钩的球按挑射键是轻轻往上顶。电脑也会争顶，传中过来的球队友会迎上去头球攻门。
- **一脚出球（配合奖励）**：队友的球还在路上（甚至队友还在蓄力准备传给你）就按下键——按住不放也行，球一到脚边就自动打出去；先按后松也行。球员会自动跑到接球点，不停球直接打：地滚球是一脚射门/一脚传，空中球会等它落到腰部高度来一脚**凌空抽射**，更高的球就自动变成头球。一脚出球的射门更准（误差只剩三成）、更快，触球判定也更宽松；回传给刚传你球的人会显示“撞墙配合”。头顶会飘出“凌空抽射! / 一脚射门! / 撞墙配合! / 鱼跃冲顶!”之类的字。自己带球射门和以前一样，没有这些加成。
- **电脑会多给你传球**：你是队里的头号接应点，只要你身边没人贴着，队友就优先传给你；你在进攻区域时，大多是高空球，一半落在头球高度、一半落在凌空抽射的高度，跑过去按射门键就是头球攻门或凌空抽射（队友传来的头球球，起跳时更容易顶到）。
- **挑射也带元素**：挑射（朝着球门、没有接应队友的挑球）是元素射门，按正常弧线吊过去；挑传也带着整条配合的元素，同样能参与连携。
- **技能后的传球**：技能中或刚放完时的技能传球，力度专门调成队友最好一脚处理的速度（地面球到脚下、挑传落在头球或凌空的高度）；放完技能 2.5 秒内一脚处理队友的来球，也算技能出脚（最舒服的力度、几乎没有偏差）。
- **电脑拿球就出手**：电脑一拿到球马上做决定——射程内射门，否则立刻传给更好的位置，基本不停球盘带。
- **电脑爱炫技**：电脑接到队友的传球，只要在射程内（比自己带球时远得多）大多一脚直接射门，高球就是凌空抽射或头球；传中会专门喂到队友的头球或凌空高度；被人挡住时更常用过人技能，技能放到一半或刚放完就直接技能射门。所以电脑之间也经常打出元素连携。
- **电脑的配合**：电脑传球都用平传，会算提前量，传之前检查传球路线上有没有人（越远检查得越宽）；对方传球时，只有正好在球路上的电脑才会去断。前锋和中场传出球后会前插要回传（二过一），接到队友的球会更常一脚射门、一脚回传或一脚转移；边路下底时会传中，禁区里的队友会头球或凌空。
- **动作**：蓄力时有引腿、侧身、张开手臂的预备动作；轻踢是脚内侧推传；起跳头球会先下蹲再收腿起跳；大力出脚时有火花；加速时身体前倾，急停时后仰；球员之间碰撞会互相挤开、贴着滑过去，不会穿模抖动。
- **界面**：屏幕中间不弹任何大字提示，进球、比分、出局都看顶部记分牌。
- **倒地和爬起**：被滑铲铲中、被火焰或重炮射门打中、被高速撞到时，球员会摔倒（从背后被撞就往前扑，正面被撞就往后倒），躺一下再撑地爬起来。
- **守门员**（6v6）：**扑救只在手套（或身体）真的碰到球时才算**——不再有门将离球还很远就“扑到了”。射门飞来时门将的双手会伸向球将要经过的位置（球冲着身体来就双手挡在球后，偏一点就伸出离得近的那只手），鱼跃时按球过线的位置和剩余时间算好扑出去的力度和方向（还会稍微往前封角度，半高球会腾空），所以画面里手套和球是在同一个地方相遇的。碰到球以后：大部分时候是扑住——能抱住就抱在碰到的地方再收回胸前，太快、用脚挡到或者是连携射门就扑出去；偶尔只是指尖碰到，球减速变向但还是往里飞。远射几乎进不了，禁区里的射门也很难打进，只有近距离打死角还有机会（测试：困难难度大力打死角，18 米 0%、12 米约 13%、6 米约 60%）。球靠近时压低重心、双手放在身前准备；扑救判断更早、扑得更快更远，单人射门（包括元素射门）接得住就直接抱在怀里，太快的就扑出去。门将在自己禁区里很“硬”：土的冲撞、火的爆炎、重炮射门、滑铲都撞不飞他（只会晃一下），只有冰能冻住他；雷、风、影、土带球过人冲到他身边时，他有很大机会直接把球扑下来抱住，不能再被技能轻松过掉。抱球时面向球场，看一眼后手抛给没人盯的队友，没人接应就大力抛向前场。
- **射门和庆祝**：大力射门出脚后身体顺势前送、小跳一步，触球瞬间低头看球。进球庆祝随机：跳舞挥手、跪地张开双臂、张开双臂当飞机、跳起来挥拳。
- **打击感**：球被踢、撞墙、落地时会被压扁再弹回，大力射门和滑铲会掀起草屑；助跑射门更有力，脚碰到球的位置偏了会踢出侧旋；手柄会震动。
- **带球**：触球跟着跑步的步点走，每只脚在往前摆的时候把球拨出去，鞋真的碰到球的那一刻球才走；球被拨出去后回到脚下，再拨下一次；急转、掉头时会用一脚拨球把球带过来，冲刺时球推得更远。只会因为射门、被铲、被对方的脚或身体碰到、撞到东西而丢球。
- **脚与球**：腿部两骨 IK 让鞋真正伸到球上；射门在脚背碰到球的那一刻才出球，带球每一下都由脚把球拨出去，停球时会用鞋底踩住球。
- **足球物理**：重力、空气阻力、旋转产生的弧线（马格努斯效应）、草地滚动阻力、反弹、门柱/横梁碰撞、球网吸收。
- **手感**：自动近身控球、首次触球停球、大力射门的顿帧和镜头震动、球的拖尾、程序化音效，带一点球场混响：射门有皮球“啪”的一声，大力射门还有低频的轰响和破空声；平传声音更圆更轻；头球、胸部停球、铲球、碰撞、门柱（金属回响）、球网、观众（欢呼里有口哨和掌声）都单独做过。每个元素有自己的一套声音，必杀射门、过人技能、铲球和打中人时都会响：雷是电弧噼啪加雷声，火是呼地烧起来的火焰声，冰是一串清脆的冰晶声和冰裂声，风是呼啸的风声和哨音，影是往下滑的幽灵和声，土是低沉的爆响和碎石声。打出凌空、撞墙配合时还有一小段上扬的提示音。
- **电脑**：难度有简单、普通、困难和女友模式（默认）。前三种正常对抗；女友模式下电脑很菜，拿到球就把球传到真人玩家脚下，不铲真人、不抢真人的球，只守自己的门，专门让真人射门。
- **模式**：本地 1–4 人（键盘最多 2 人，3、4 号玩家用手柄），或联机房间（最多 4 人，房间号加入）；地图分经典圆场 / 方块乐园，模式分四门混战 / 2v2 组队 / 6v6 比赛（固定用六人制球场），电脑分简单 / 普通 / 困难 / 女友模式；支持手机触屏。
- **场外**：三面糖果色看台坐满会跟着蹦的观众（进球时全场跳起来，看台上空放烟花），看台两头系着气球串，场边挂彩旗；远处有热气球、摩天轮、城堡、彩虹和飘着的云。
- **画面**：粉色花海与樱花树环绕的球场，各队球门区按颜色区分，白色中圈、彩虹足球和彩虹拖尾。

## 本地运行

```bash
node server/server.js        # 需要 Node 18 以上，不用安装任何依赖
# 打开 http://localhost:8080
```

这个服务器同时提供网页和联机房间。只玩本地模式的话，任何静态服务器都可以（例如 `python3 -m http.server`），但不能直接双击 `index.html`。

## 联机部署（让国内的家人也能一起玩）

联机时，比赛在**房主的浏览器**里运行，服务器只负责转发消息，所以服务器很省资源。国内直接访问 GitHub Pages 和 claude.ai 都不稳定，最稳妥的办法是租一台**香港**的云服务器：国内访问快，而且香港服务器不需要 ICP 备案。

1. 买一台香港的轻量云服务器，例如腾讯云轻量应用服务器或阿里云的香港地域，最便宜的套餐就够用，系统选 Ubuntu 24.04（自带的 Node.js 版本够用）。
2. 在服务器的防火墙或安全组里放行 TCP 80 端口。
3. 登录服务器，安装 Node.js 并取下代码：
   ```bash
   sudo apt update && sudo apt install -y nodejs git
   node -v                      # 需要 18 以上；版本太旧可以改用 NodeSource 的安装脚本
   git clone https://github.com/<你的用户名>/<仓库名>.git pocket-football
   cd pocket-football
   ```
   如果服务器访问 GitHub 慢，也可以在自己电脑上把整个文件夹压缩后用 `scp` 传上去。
4. 让它在后台常驻（开机自启）：
   ```bash
   sudo tee /etc/systemd/system/pocket-football.service > /dev/null <<UNIT
   [Unit]
   Description=Pocket Football
   After=network.target
   [Service]
   WorkingDirectory=$PWD
   ExecStart=$(which node) server/server.js
   Environment=PORT=80
   Restart=always
   [Install]
   WantedBy=multi-user.target
   UNIT
   sudo systemctl enable --now pocket-football
   ```
5. 所有人用浏览器打开 `http://服务器的公网IP/`，进“联机对战”：一个人创建房间，把 4 位房间号发给其他人加入，房主点开始。人不够 4 个时，剩下的球门由电脑守。

**谁当房主：** 房主的网络延迟最低，其他人的操作要先到服务器再到房主那里。如果三个人在国内、一个人在国外，让国内的人创建房间，整体延迟最小。国外的玩家会有大约 0.2–0.3 秒的操作延迟，打得开心没问题，但抢球时会感觉慢半拍。

**其他说明：** 用手机或电脑上的 Chrome、Edge、Safari 打开效果最好，微信内置浏览器也能用但性能差一些。浏览器只在 HTTPS 页面里允许读取手柄，所以用 IP 访问时手柄不能用（联机本来也是每人一台设备，用键盘或触屏即可）。想要域名和 HTTPS，可以给服务器绑一个域名，用 Caddy 反向代理到 80 端口；在中国大陆以外注册域名、指向香港服务器同样不需要备案。

## 换成你自己的角色

把任何 VRM 1.0 模型（例如用 VRoid Studio 捏的原创角色，导出时选 VRM 1.0）放到 `assets/models/player.vrm` 即可，动画会自动重定向，踢球的接触点也会按新模型的腿长自动校准。可以先用 `tools/prepare_vrm.py` 去掉法线贴图和缩略图来减小体积。

**第一人称视角**：按 `C`（或右上角“视角”）切到第三档，镜头放在你操控的球员眼睛的位置，视野更宽、稍微往下看，脚下的球也看得到；镜头跟着身体方向转，但转得比身体慢一点，急转身不会甩头。第一人称时方向键按你看的方向走（上 = 往前），左下角会显示小地图，自己的名字和蓄力条固定在屏幕下方。换人后镜头跟到新的球员身上。这个视角会晃，容易晕的话按 `C` 切回固定视角。
